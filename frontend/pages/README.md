# Páginas del periódico

Cada sección del periódico debe poder crecer hacia una página independiente. Por ahora esta carpeta organiza la capa de presentación; no introduce backend ni cambia el stack.

Estructura prevista:

- `home/` — portada
- `nacionales/` — noticias nacionales
- `economia/` — economía
- `deportes/` — deportes
- `cultura/` — cultura y entretenimiento
- `mundo/` — mundo
- `opinion/` — opinión
- `editorial/` — editorial
- `provincias/` — provincias

Los componentes compartidos deben permanecer fuera de estas carpetas para evitar duplicación.
